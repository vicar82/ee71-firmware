# Восстановление EE71 после неудачной прошивки (unbrick)

> Работает, если роутер «кирпич»: все LED горят/мигают, Wi-Fi нет, вебморда не открывается.
> IMEI и радиокалибровка (раздел efs2) этой процедурой НЕ трогаются.
> Авторство идеи и инструментов: vicar82/ee71-firmware.

## Что понадобится

- Этот архив (unbrick-kit): `stock-sysfs.ubi`, `stock-jrdresource.ubi`, `mtdwriter`
- `adb` — Windows: возьмите `adb.exe` из основного пакета прошивки
  (`Flash+Firmware.../adb.exe`), macOS: `brew install android-platform-tools`,
  Linux: пакет `adb` дистрибутива.

## Шаг 1 — войти в recovery-режим

1. Выключите роутер (зажать кнопку питания).
2. Снимите крышку, **зажмите кнопку под батареей** (рядом с SIM).
3. **Не отпуская кнопку**, включите роутер кнопкой питания.
4. Держите, пока LED **не начнут мигать по очереди** (по кругу). Отпустите.
5. Подключите роутер USB-кабелем к компьютеру.

Проверка: `adb devices` — должен появиться серийник со статусом `device`
(на Windows, если спросит драйвер — установите Google USB Driver или драйвер
ADB вашего устройства; если вместо adb виден только COM-порт/диск — см. раздел
«если adb не появляется» в конце).

## Шаг 2 — залить стоковые образы

Выполняйте из папки с файлами набора, **не прерывая**, каждая команда — до её
завершения (образ system ~42 МБ пишется несколько минут):

```
adb push stock-sysfs.ubi /tmp/
adb push stock-jrdresource.ubi /tmp/
adb push mtdwriter /tmp/
adb shell "chmod 755 /tmp/mtdwriter"
adb shell "/tmp/mtdwriter /dev/mtd15 /tmp/stock-sysfs.ubi"
adb shell "/tmp/mtdwriter /dev/mtd14 /tmp/stock-jrdresource.ubi"
```

Каждый запуск mtdwriter должен закончиться строкой `VERIFY OK`.
Если verify не сошёлся — НЕ перезагружайтесь, повторите команду для этого раздела.

## Шаг 3 — перезагрузка

```
adb reboot
```

Первая загрузка ~1–2 минуты: LED покрутятся, появится Wi-Fi `4GEE-WiFi-XXXX`/
`ALCATEL-EE71-XXXX`. Вебморда: `http://192.168.8.1`.

Роутер вернулся к заводской (вендорской EE71_E1_02.00_36) прошивке.

## Диагностика (пришлите автору, если не помогло)

В recovery до шага 2 выполните и сохраните вывод:

```
adb shell "cat /proc/mtd"
adb shell "dmesg | tail -40"
```

## Если adb не появляется

Recovery на некоторых компьютерах определяется только как диагностический
COM-порт и CD-ROM (без adb). Тогда восстановление — через режим EDL:

1. Разрядите/выключите роутер; зажмите кнопку под батареей и подключите USB —
   устройство определится как **Qualcomm HS-USB QDLoader 9008** (Windows:
   в Диспетчере устройств).
2. Установите QPST/QFIL (2.0.2.3+), выберите программер `NPRG9x45.mbn`
   (лежит в `images/` основного пакета) и залейте стоковые образы разделов
   по их адресам из `partition.mbn`.
3. Этот путь — крайняя мера; если не уверены — пишите в тему прошивки,
   поможем.
