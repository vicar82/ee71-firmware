# Прошивка EE71 — инструкция (v2, безопасная)

## Главное правило

**`efs2` (раздел с IMEI и радиокалибровкой) НИКОГДА не прошивается** — ни в одном
скрипте этого пакета. Именно прошивка efs2 шаблонным `efs.mbn` превращает чужой
роутер в кирпич без IMEI. `efs.mbn` оставлен в `images/` только для справки и
ни одним скриптом не используется.

## Что есть в папке

| Файл | Назначение |
|---|---|
| `Flash-Update-v2.cmd` | **Основной**: обновление system + jrdresource до наших сборок v1.3 |
| `Flash-Full-v2.cmd` | Полный комплект (boot chain + modem + всё), с подтверждением YES |
| `flash.sh` | То же, что Update-v2, для macOS/Linux |
| `images/mdm9640-sysfs-v1.ubi` | наш system (ubi0: rootfs+usrfs) |
| `images/jrdresource-v1.ubi` | наш jrdresource (вебморда, скрипты) |
| `images/mdm9640-sysfs.ubi`, `images/jrdresource.ubi` | **стоковые откатные образы** |
| `Flash-Firmware-Fastboot.stock.cmd` | оригинальный скрипт пакета (прошивает efs2 — НЕ ИСПОЛЬЗОВАТЬ) |

## Перед прошивкой

1. **Заряд минимум 50%** (прерывание питания во время записи раздела — восстановимо через fastboot, но неприятно).
2. **USB-кабель** напрямую в порт (без хабов).
3. Windows: драйверы ADB/fastboot (при первом подключении предложит установить).
4. Устройство должно быть **загружено** (не в recovery/fastboot).

## Прошивка (Windows)

```
Flash-Update-v2.cmd   (двойной клик)
```

Скрипт сам: проверит adb → снимет **бэкап EFS** в `efs2-backup.img` (обязателен,
без него не прошьёт) → перезагрузит в fastboot → прошьёт system+jrdresource →
перезагрузит. Первая загрузка ~1 минута.

Если adb не видит роутер (USB в режиме модема/CD-ROM) — сначала выполни
`EE71_Fix.ps1 -Comp 33` (из старого пакета) или переключи композицию в
вебморде: Настройки → USB.

## Прошивка (macOS/Linux)

```
sh flash.sh
```

Требует `adb`/`fastboot` (`brew install android-platform-tools`).

## Откат

Роутер не загрузился / не понравилось — всё возвращается:

```
fastboot flash system images/mdm9640-sysfs.ubi
fastboot flash jrdresource images/jrdresource.ubi
fastboot reboot
```

(устройство входит в fastboot командой `adb reboot bootloader` или кнопкой
под батареей при включении → recovery → fastboot)

## Если совсем плохо

Кнопка под батареей (Recovery) при включении → recovery-режим → отсюда всегда
доступен fastboot. Цепочка sbl→aboot не трогается никакими скриптами v2,
поэтому hard-brick недостижим.

## Восстановление EFS из бэкапа

Крайняя мера (после осознанных экспериментов с efs2 — скрипты v2 этого не делают):

```
adb shell dd of=/dev/mtdblock2 if=/tmp/efs2-backup.img bs=65536
```
(файл предварительно залить на устройство через adb push; **роутер при этом
должен быть перезагружен с обесточенным модемом** — батарея наружу на минуту)
