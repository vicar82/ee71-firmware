# EE71 Custom Firmware v1.3

Кастомная прошивка для мобильного 4G-роутера **Alcatel EE71** (TCL T77W676, Qualcomm MDM9640, LTE Cat 7).

Собрана на базе вендорского пакета `EE71_E1_02.00_36` (сентябрь 2025) и работы
[rctphone/Entware-EE71-glibc2.17](https://github.com/rctphone/Entware-EE71-glibc2.17).

> **Внимание.** Всё, что вы делаете с устройством — на ваш страх и риск.
> Прошивка модифицирует системный раздел; гарантия при этом теряется.
> Раздел `efs2` (IMEI и радиокалибровка) прошивкой **не затрагивается ни при каких
> сценариях** — все скрипты этого пакета исключают его, а перед прошивкой делается
> его бэкап.

## Что внутри (фичи)

### Веб-интерфейс (`192.168.8.1`, логин `admin`, пароль `12345678`)

- **Диагностика** — график сигнала за 12 часов, таблица агрегации несущих (CA), уровни RSRP/RSRQ/SINR по каждой ячейке.
- **LTE-диапазоны** — честное отображение текущих диапазонов и CA из live-данных модема (читается каждые 5 с).
- **LAN** — статические DHCP-аренды (привязка IP к MAC без правки конфигов).
- **Wi-Fi** — расписание сна радиомодуля (выключается на ночь по cron).
- **SSH** — страница управления dropbear: вкл/выкл, режим «только ключи» (без пароля).
- **TTL-фикс** — страница включения/выключения фиксации TTL (для раздачи).
- **Speedtest** — встроенный замер скорости.
- **SMS** — чтение/отправка, удаление, пересылка на другой номер (sms-forward).
- **USSD** и **AT-терминал** прямо из браузера.
- **VPN** — инструменты WireGuard/AmneziaWG (ядро с модулем).
- **Резервная копия** настроек в файл и восстановление.
- **Страница «Питание»** — перезагрузка, расписание.
- Интерфейс на русском и английском.

### Система

- **TTL-фикс 64 из коробки** (iptables mangle на rmnet+, с watchdog-cron).
- **Entware (opkg) под `/usr`** — glibc 2.17 совпадает со стоковым libc, пакеты не тащат вторую libc. Фид пакетов: `https://raw.githubusercontent.com/rctphone/ee71-opkg/main` (настройка `/etc/opkg.conf` по желанию, см. [webui/INSTALL.md](webui/INSTALL.md)).
- **Dropbear SSH** — root-доступ по сети (пароль задаётся при первом входе по схеме устройства).
- **Кастомные DNS для LAN** (dnsmasq, по умолчанию Яндекс 77.88.8.8/77.88.8.1 — меняется в `dns.conf`).
- **BusyBox 1.36** (в стоке 1.20 — у нового корректный `timeout -k` и прочее).
- **USB-композиция с авто-детектом ОС**: при подключении к Mac/Windows поднимается полный набор (диагностика + ADB + сеть + CD-ROM) — патч ядра при загрузке.
- **Оптимизации загрузки** (параллельный старт сервисов), фиксы зарядки, Wi-Fi и QCMAP из пакетов rctphone.
- **IPv6** (kmod-nat66), статистика трафика, CSP-заголовки веб-сервера.

### Честно о том, чего нет

- **Блокировка LTE-диапазонов из вебморды невозможна** — карьерный конфиг (mcfg) в подписанном модемном образе перезаписывает NV при каждой загрузке. Страница диапазонов показывает реальные band'ы и объясняет это. Подробности исследования: [docs/RESEARCH.md](docs/RESEARCH.md).
- **Cat 9 не включён** — экспериментально нестабилен (зависания); остаётся стоковый Cat 7 с 2CA/3CA по решению сети.
- **iperf3 из Entware требует `opkg install libatomic`** (иначе не стартует).

## Установка

> Требуется роутер с заводским (вендорским) загрузчиком — он подписан, и наши
> образы его не меняют. Заряд батареи ≥ 50 %, кабель напрямую в порт.

### Windows

1. Скачай `EE71-firmware-v1.3.zip` из [Releases](../../releases) и распакуй.
2. Подключи роутер USB-кабелем. Если он определился как CD-ROM/модем — в вебморде
   (Настройки → USB) переключи композицию так, чтобы появился **ADB**-интерфейс,
   либо воспользуйся любым TCL USB Switch Tool.
3. Запусти **`Flash-Update-v2.cmd`** двойным кликом (права администратора не нужны,
   но драйвер ADB при первом подключении установится сам через Windows Update;
   если нет — поставь [Google USB Driver](https://developer.android.com/studio/run/win-usb)).
4. Скрипт сам: проверит adb → снимет **бэкап EFS** в `efs2-backup.img`
   (обязателен — без него прошивка не начнётся) → перезагрузит в fastboot →
   прошьёт `system` + `jrdresource` → перезагрузит роутер.
5. Первая загрузка ~1 минута. Вебморда: `http://192.168.8.1`, `admin` / `12345678`.

Ручной вариант (если батник не работает) — командная строка из папки пакета:

```
adb reboot bootloader
fastboot flash system    images/mdm9640-sysfs-v1.ubi
fastboot flash jrdresource images/jrdresource-v1.ubi
fastboot reboot
```

### macOS

```sh
brew install android-platform-tools
cd <папка пакета>
sh flash.sh
```

Скрипт делает то же самое: бэкап EFS → fastboot → прошивка → перезагрузка.
Драйверы не нужны — macOS сам поднимает сетевой интерфейс роутера.

### Linux

```sh
sudo apt install adb fastboot      # Debian/Ubuntu; в других дистрибутивах — аналог
cd <папка пакета>
sh flash.sh
```

Пользователь должен быть в группе, имеющей доступ к USB (обычно `plugdev`).

## Откат на сток

В пакете лежат **стоковые откатные образы** (`images/mdm9640-sysfs.ubi`,
`images/jrdresource.ubi`). Прошить их тем же путём, что и установку
(ручными командами выше, подставив стоковые файлы, либо поправив пути в скрипте).

Полный возврат к заводскому состоянию (все разделы, кроме efs2 — IMEI не трогаем):

```
Flash-Full-v2.cmd
```

> Файл `images/efs.mbn` — шаблонный EFS2 без IMEI. **Никогда** не прошивайте его.
> Оригинальный скрипт пакета `Flash-Firmware-Fastboot.stock.cmd` делает именно
> это — он оставлен только для справки.

## Восстановление после неудачной прошивки

1. **Recovery-режим**: выключи роутер → зажми кнопку под батареей → включи,
   держи до поочерёдного мигания всех LED → подключи USB → `adb shell`.
   Recovery НЕ трогает system/jrdresource — там можно подняться и перепрошиться.
2. **Восстановление boot** (если устройство вообще не грузится): recovery + adb,
   инструмент `mtdwriter` (erase→write→verify) — исходники в [docs-mtdtools/](docs-mtdtools),
   рабочий сценарий описан в [docs/RESEARCH.md](docs/RESEARCH.md).
3. **EDL (последний ресурс)**: короткое замыкание/кнопка → порт 9008 → QFIL с
   программерами `NPRG9x45.mbn` / `ENPRG9x45.mbn` (лежат в `images/`).

## Структура репозитория

| Путь | Содержимое |
|---|---|
| `system/` | корневая файловая система и usrfs (исходники образа `system`) |
| `jrdresource/` | вебморда, конфиги JRD, кастомные бинарники (образ `jrdresource`) |
| `modem/` | распакованный NON-HLOS (модемный стек, для исследований) |
| `boot/` | zImage, dtb, хвост подписи boot (справочно; boot не модифицируется) |
| `recoveryfs/` | recovery-окружение |
| `flash/` | скрипты прошивки и инструкция (образы — в архиве релиза) |
| `webui/` | исходники веб-интерфейса (история сохранена, на базе rctphone) |
| `build/` | конфиги `ubinize` для сборки образов |
| `docs-mtdtools/` | исходники mtdscan/mtdwriter (восстановление) |
| `docs/RESEARCH.md` | исследование: mcfg, подпись boot/modem, выводы |

## Сборка образов

Образы собираются Linux-окружением (`ubinize`, геометрия PEB 131072 / LEB 126976,
конфиги в `build/`). Вебморда — node + esbuild (`webui/feeds/rctphone/ee71/ee71-webui`).
Большие UBI-образы в git не входят — они публикуются ассетами релиза.
